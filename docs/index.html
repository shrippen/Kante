Kante

One style for the web and for apps: the same palette, type, shapes and roles on landing pages and in Qt Quick, Kirigami and Plasma. Every box has its top-right corner cut, the edge (Kante) that gives the system its name.

Ein Stil für Web und Apps: dieselbe Palette, Schrift, Formen und Rollen auf Landing Pages und in Qt Quick, Kirigami und Plasma. Jede Fläche hat ihre obere rechte Ecke abgeschnitten, die Kante, nach der das System heißt.

Plus shrippen.js for the language switch, copy buttons and tabs. Apps copy the QML module qml/Kante unchanged.

Dazu shrippen.js für Sprachumschalter, Kopierknöpfe und Tabs. Apps kopieren das QML-Modul qml/Kante unverändert.

Landing Pages und Web-Apps

One built stylesheet with tokens, base styles and components: hero, feature boxes, tabs, dialogs, tables, conversations. Every shrippen landing page links it, so a change here reaches all of them.

Qt Quick · Kirigami · Plasma

Apps and widgets

Apps und Widgets

The QML module Kante brings the same shapes, sizes and motion to apps, KantePlasma wraps the Plasma components for widgets. Tested with qmltestrunner on every build.

Das QML-Modul Kante bringt dieselben Formen, Größen und Bewegungen in Apps, KantePlasma umhüllt die Plasma-Komponenten für Widgets. Bei jedem Build mit qmltestrunner getestet.

Use it

Einbinden

  1. Landing page: start from templates/landing.html, it links the stylesheet.
  2. Offline web app: vendor shrippen.css, shrippen.js, fonts.css and fonts/ from https://shrippen.github.io/v1/ unchanged.
  3. Qt Quick / Kirigami app: copy qml/Kante; Plasma widget: also qml/KantePlasma.
  4. Missing something? It goes into Kante first, then into the project.
  1. Landing Page: mit templates/landing.html anfangen, sie bindet das Stylesheet ein.
  2. Web-App ohne Netz: shrippen.css, shrippen.js, fonts.css und fonts/ von https://shrippen.github.io/v1/ unverändert übernehmen.
  3. Qt-Quick-/Kirigami-App: qml/Kante kopieren; Plasma-Widget: zusätzlich qml/KantePlasma.
  4. Fehlt etwas? Es kommt zuerst in Kante, dann ins Projekt.

For Kimai: Knust and the plugin kit

Für Kimai: Knust und das Plugin-Kit

Knust is Kante's spinoff for Kimai, a theme plugin on top of Tabler with its palette generated from Kante. The plugin kit (kpu-* macros, CSS and JS) says what an element is; Knust decides how it looks. Both live in this repository.

Knust ist Kantes Ableger für Kimai, ein Theme-Plugin auf Tabler, dessen Palette aus Kante erzeugt wird. Das Plugin-Kit (kpu-*-Makros, CSS und JS) sagt, was ein Element ist; Knust entscheidet, wie es aussieht. Beide liegen in diesem Repository.
