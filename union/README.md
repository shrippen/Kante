# Kante for Union (spike)

Kante as a style for [Union](https://invent.kde.org/plasma/union), KDE's style engine (Qt Quick, Qt Widgets, Plasma SVG outputs; CSS input). Generated from `tokens/palette.json` like the QML module, so it follows the palette without a second copy.

| Path | What |
|---|---|
| `styles/kante/`, `styles/kante-light/` | Union CSS styles (dark, light "Leinen"): `metadata.json`, `contents/css/{style,variables,controls}.css` |
| `colors/Kante.colors`, `KanteLight.colors` | KDE colour schemes from the same roles (Plasma, Qt widgets, GTK follow them) |
| `template/controls.css` | The only hand-written file: window, label, buttons, tool buttons, fields. No raw colours, only `var(--k-*)` |
| `union-properties.txt` | Property names Union's CSS input knows (from its property reference), used by `tools/check-union.py` |

Generated by `tools/build-union.py` (`./build.sh`). Edit the palette or `template/controls.css`, never the generated files.

## Try it

```bash
mkdir -p ~/.local/share/union/css/styles
cp -r kante/union/styles/kante ~/.local/share/union/css/styles/
UNION_STYLE_NAME=kante QT_QUICK_CONTROLS_STYLE=org.kde.union qml -I kante/qml kante/qml/demo/Gallery.qml
```

Colour scheme: copy `colors/Kante.colors` to `~/.local/share/color-schemes/` and pick it in System Settings.

## What was checked

- `tools/check-union.py` (part of `./build.sh`): every property is in Union's list, only supported states and combinators, no raw colours or fonts in the template, every `--k-*` is defined, generated files are current.
- Union's own CSS parser ([cxx-rust-cssparser](https://invent.kde.org/libraries/cxx-rust-cssparser), `StyleSheet::parse` after Union's `defaults/default.css`) parses both styles with 74 rules and 0 errors; an unknown property is reported (`UnknownProperty`), so this is a real check. Against Union master `688109c` (2026-09-30).
- **Not checked: how it looks.** Union needs Qt 6.9 and a C++ build; the spike was made where neither was available, so nothing has been rendered yet.

## Gaps

| Kante | In Union | Consequence |
|---|---|---|
| Top-right corner cut (16 / 10 / 6 px), second cut on primary and danger buttons | CSS input only has `border-radius` (per corner) | **No cut.** Corners are square, which is Kante's field look, but surfaces and buttons lose the signature. Needs an upstream shape property (e.g. a clip or corner-cut length) or the Plasma SVG input |
| Motion (`KanteStyle.motion`, reduced-motion aware) | Transitions and animations are unsupported | Static; states switch instantly |
| Rajdhani headings, uppercase labels | One `font-family` per element, no heading element; fonts are the platform's | Platform font everywhere for now |
| Tints over a translucent ground | Window background is painted by the style | Ground is opaque (`--k-ground`); card and sunken tints are alpha over it |
| Primary (yellow) button | `button:highlighted` (QQC2 `Button.highlighted`) | Only apps that set `highlighted` get it; Kirigami's `Primary` hints are not mapped yet |
| Plasma shell (panel, popups, widget backgrounds) | Plasma SVG theme, separate from Union CSS styles | Not covered; the colour scheme recolours what follows it |

## Not built yet

Check box, radio, switch, slider, progress bar, scroll bar, tabs, menus, tool tips, tables, Kirigami. The template shows the pattern (state selectors on Union element names, roles from `variables.css`); the Breeze style in Union's repository (`src/input/css/styles/breeze`) is the map of what each needs.
